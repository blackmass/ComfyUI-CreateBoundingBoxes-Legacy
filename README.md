# ComfyUI-CreateBoundingBoxes-Legacy
 This adds a new node that enables the 'create bounding boxes' functionality—previously available only in Node 2.0—to work in Node 1.0 as well.
# function
- basic : The basic operation is the same.
- resize : The width and height values ​​generated by the "Resolution Selector" are applied and updated in real-time before ComfyUI is launched.
